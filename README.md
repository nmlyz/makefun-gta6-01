Neon Bay is a top-down open-world crime game: drive, steal cars, outrun the police and run missions across a neon city.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD/arrows to move and drive, E to steal a car, SPACE handbrake, P pause, M mute, R restart, ENTER to take a mission.
