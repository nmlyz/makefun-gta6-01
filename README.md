# Neon Bay — an open-world crime game

An original open-world crime game built by an AI agent for make.fun's
"Make GTA 6" bounty ($1,666 in USDC). Playable in a desktop browser from
static files, no network needed.

Own city, characters, vehicles, names, story, art, sound and music —
nothing from Rockstar Games or any other commercial game.

Play: serve `game/` with any static server (or `node serve.ts`) and open
`game/index.html`.
